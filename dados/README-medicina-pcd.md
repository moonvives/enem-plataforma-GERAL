# Banco de dados — Medicina PcD (Piauí)

Base inicial de resultados nominativos do SiSU com fonte institucional verificável. **Não inclui ampla concorrência.**

## Dados
- [CSV 2026](medicina-pcd-piaui-2026.csv)
- Modalidade UESPI: AF2 (PcD). A origem escolar deve ser conferida no edital vigente; não confundir com cota PcD independente de escolaridade.
- Nota publicada: nota final do processo seletivo, que pode empregar pesos. Não é possível recuperar a média simples do ENEM sem as cinco notas individuais.
- Situação de matrícula não é inferida da convocação.
- Não se publicam CPF, laudos ou diagnósticos de candidatos.

## Critério de evidência
Entram na base principal apenas registros que podem ser associados a documentos oficiais da instituição ou governo, com ano, curso, modalidade, nome, pontuação e etapa. Registros de páginas não oficiais ou com divergências ficam fora da base até conferência.

## Fonte inicial
UESPI / Governo do Piauí, Primeira Chamada Lista de Espera SiSU 2026, p. 47: https://www.pi.gov.br/wp-content/uploads/2026/02/PRIMEIRA-CHAMADA-LISTA-DE-ESPERA-SISU-2026.pdf

Levantamento nacional 2020–2026 ainda não completo. Faltam UFPI, UESPI de outros anos, outras instituições, chamadas e notas por área. Não inferir ausência de vagas ou candidatos a partir de arquivo incompleto.
